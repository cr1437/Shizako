## 🔴 必须解决（否则会被拒或被要求整改）

### 1. 内置自动更新器 —— 与 F-Droid 直接冲突

代码里会从 GitHub Releases **下载 APK 并安装**（`UpdateChecker.downloadAndInstall`）。
F-Droid 明确不接受自更新：他们用自己的密钥签名，应用自我更新会换成 GitHub 的签名，
**在 F-Droid 用户设备上必然安装失败**，还会绕过 F-Droid 的分发渠道。

→ 建议：加 `fdroid` 构建变体，**关掉自动更新与下载安装**（保留「检查更新」提示，或整块去掉）。

### 2. `manager/src/main/assets/shizako-stub.apk`（868 KB，直接提交的产物）

F-Droid 要求一切二进制由源码构建。
→ 把 stub 模块源码纳入构建（或 recipe 用 `srclibs`），构建时生成该文件。

### 3. 「一键注入」会下载并安装第三方应用的 APK

`RecommendedApps` 指向 `github.com/cr1437/apk-mirror` 下载别的 App 安装包并调用安装。
这既是分发第三方二进制，也与「禁止绕过商店安装应用」的政策相抵触。
→ 建议 fdroid 变体同样关闭该功能。
