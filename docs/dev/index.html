开发文档

编译与参与开发 →

环境要求（JDK 17 / SDK 36 / NDK 29）、编译命令、签名注意事项、代码结构与维护脚本。

更新日志 →

各版本的对外更新内容，与 GitHub Releases 的说明保持同步。

只是想用官方依赖？

直接依赖 dev.rikka.shizuku:api 与 dev.rikka.shizuku:provider 即可 —— Shizako 对官方 API 应用是免改码直连的，你不需要为它写任何适配代码。
