zako3.12 更新日志#

激活可靠性大修 + 全面性能优化，强烈建议所有用户升级。

✨ 新功能#

  • 每次打开 App 自动检查更新，发现新版本就地弹出可下载的对话框（不再只依赖通知栏）
  • 更新检查自动挑选可用源：GitHub API 被网络拦截时自动切换镜像，国内网络同样能收到更新

🔧 修复与优化#

  • 激活：
  • 修复「电脑 ADB」激活必失败（启动命令缺少 APK 路径参数）
  • 修复 Dhizuku 一键激活必失败（命令带了电脑端前缀，却在设备上执行）
  • 修复看门狗 / 开机自启 / 快捷磁贴重启服务时用错启动方式
  • 修复无线调试配对可能永久卡在「配对中」（补连接与读取超时）
  • 修复服务端一处空指针：同一进程二次连接时应用会永久收不到服务，且界面看不出异常
  • 修复共享 uid 下只有第一个包能收到服务的漏推问题
  • 首次引导：修复 Android 7.x 闪退、Android 11/12 点激活无反应、倒计时被转屏重置等 17 处问题
  • 更新检查：改为按版本号逐段比较，只认「确实更新」，避免把旧版本当作新版本推送
  • 问题反馈：修复 #5（Dhizuku 缺少开关）、#6（深色模式黑字）、#7（模块搜索不到）
  • 性能与耗电：
  • 启用 Baseline Profile：冷启动实测提升约 15% ~ 20%
  • 后台保活轮询 12 秒 → 45 秒，去掉无用的周期性唤醒，明显降低耗电与闪存写入
  • 应用列表图标改为真正命中缓存（此前每次新建项都走主线程加载）
  • 界面噪点纹理全应用共用，窗口底图内存减半

🌍 English#

Activation reliability overhaul + broad performance work — strongly recommended for all users.

  • New: check for updates on every app launch, with an in-app download dialog; automatic mirror fallback when the GitHub API is blocked by your network
  • Fixed: "Computer ADB" and one-tap Dhizuku activation never worked; watchdog / boot / quick-tile restarting the service with the wrong launch method; wireless pairing could hang forever; a server-side NPE that left an app permanently without the service; shared-UID binder push skipping all but the first package
  • Fixed 17 issues in the first-run setup wizard (Android 7.x crash, no-op activation on Android 11/12, countdown reset on rotation)
  • Update check now compares version numbers instead of string inequality (no more downgrade prompts)
  • Fixed issues #5 / #6 / #7
  • Performance: Baseline Profile enabled (~15–20% faster cold start), background keep-alive polling 12s → 45s, real icon-cache hits, shared noise texture, half the background bitmap memory

zako3.01-hp 更新日志#

紧急修复版，强烈建议所有用户升级。

  • 修复「激活」可能一直转圈、卡住无反应的问题：新增超时保护，未完成配对时会明确提示
  • 修复启动失败时误关「无线调试」开关的问题（失败后可立即重试）
  • 修复控制台列表弹窗偶发闪退
  • 一并加强：「分屏配对」对话框（不用电脑也能走完配对流程）+ 持久 TCP 模式（默认开启，断网也能一键启动）

zako3.01 更新日志#

玻璃 / Material 3 双风格领衔：zako3 系列首个版本，整套系统全面重做，外加一整套新玩具。更新后建议先逛逛「工具箱」和「设置」～

✨ 新功能#

  • 玻璃 / Material 3 双风格全新界面：KernelSU 风格重做，一键切换、深浅色与动态取色全适配
  • 一站式激活：Root / 无线调试 / 电脑 ADB / Dhizuku 一页搞定；已配对可一键启动
  • 全新工具箱：模块 / 控制台 / 无障碍管理器 / 实验室 / 推荐应用
  • 首次引导全面重构：七页五步，内嵌配对指引
  • 更新欢迎页：老用户升级后首次打开可见

🔧 修复与优化#

  • 修复动态取色下部分按钮 / 图标颜色不同步
  • 修复主页与激活页状态显示不一致
  • 滚动、切页等性能与动画细节优化
